# Rainbow6_Signal_UE

원티드 게임잼 1팀 - 레인보우 식스 시그널 언리얼 리포지토리

## 프로젝트 개요

**Rainbow6_Signal**은 언리얼 엔진 5를 사용하여 개발한 군용 수신호 훈련 프로그램입니다. 이 프로그램은 플레이어가 아군을 구출하러 적진을 몰래 진입하는
긴장감 넘치는 임무를 수행하는 경험을 제공합니다. 특히, 미리 정해진 경로(스플라인)를 따라 이동하며, 특정 지점에서 발생하는 이벤트에 수신호로 대응하며, 
웹캠으로 수집한 화면을 AI 서버로 전송해 평가하고 피드백을 받는 독특한 게임 플레이를 특징으로 합니다.

## 주요 특징

-   **1인칭 시점**: 플레이어는 현장감 넘치는 1인칭 시점으로 게임을 플레이합니다.
-   **스플라인 기반 이동**: 캐릭터는 디자이너가 설계한 특정 경로를 따라 자동으로 이동하며, 플레이어는 주변 상황에 집중하고 대응하는 역할을 맡습니다.
-   **웹캠 수신호 촬용**: 언리얼 클라이언트는 사용자의 움직임을 웹캠으로 녹화하여 AI 서버로 전송합니다.
-   **심리적 요소**: AI 사운드 오버 생성형 에셋들은 단순한 전투를 넘어, 가스 공격이나 폭격과 같은 상황에서 캐릭터가 겪는 심리적 반응을 표현하여 게임의 몰입감을 높입니다.
-   **AI 서버**: AI 서버는 미디어 파이프 등의 기술을 통해 사용자의 움직임을 특정 수신호로 분류하고 유사도를 평가합니다. 

## 프로젝트 구조

-   `Content/`: 게임의 모든 에셋(맵, 캐릭터, 블루프린트, UI 등)이 저장됩니다.
    -   `Blueprints/`: 핵심 게임플레이 로직을 담은 블루프린트가 있습니다.
    -   `Map/`: `IntroMap`, `GameMap`, `EndingMap` 등 다양한 게임 레벨이 존재합니다.
    -   `Source/`: 게임의 C++ 소스 코드가 위치합니다.
        -   `Rainbow6_SignalCharacter.h`: 플레이어 캐릭터의 C++ 클래스로, 스플라인 이동과 같은 핵심 기능이 정의되어 있습니다.
        -   `Rainbow6_SignalGameMode.h`: 게임의 기본 규칙을 정의하는 게임 모드 클래스입니다.
-   `Config/`: 프로젝트의 기본 설정 파일이 있습니다.
-   `Rainbow6_Signal.uproject`: 언리얼 엔진 프로젝트 파일입니다.

## 시작하기

1.  이 리포지토리를 클론합니다.
2.  `Rainbow6_Signal.uproject` 파일을 Unreal Engine 5.6 버전으로 엽니다.
3.  `Content/Map/` 폴더에 있는 맵 중 하나를 열어 프로젝트를 탐색하거나 플레이할 수 있습니다.

## 기술 스택

-   **엔진**: Unreal Engine 5.6
-   **주요 모듈**:
    -   `UMG`: 사용자 인터페이스(UI)를 위해 사용됩니다.
